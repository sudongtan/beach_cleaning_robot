# Assets

Everything in `sim/common/meshes/` and `sim/common/textures/` is generated by `sim/common/make_assets.py` (`make assets`) from code in this repo. No third-party files are involved, so the project's own license applies.

| Asset | Source | License |
|---|---|---|
| Trash meshes (`pet_bottle_*`, `can_330`, `food_tin`, `glass_*`, `poly_cup`, `cigarette_pack`, `food_container`) | procedural (surfaces of revolution and boxes), `make_assets.py` | this repo |
| Trash visuals (B5): `meshes/<item>_print.obj`, `meshes/<item>_body.obj`, `textures/<item>.png` | procedural, UV-mapped meshes and texture atlases, `trash_visuals.py` (run by `make assets`); labels are invented and brand-free; text drawn with DejaVu Sans Bold when installed (Bitstream Vera license, free to use and embed) | this repo |
| Distractor meshes (`shell`, `rock_*`, `seaweed`, `driftwood`) | procedural (noisy ellipsoids, box strips, surface of revolution) | this repo |
| `bin`, `lifeguard_tower`, `fence_post` | procedural (boxes, surface of revolution) | this repo |
| `sand_albedo.png`, `sand_normal.png`, `wet_sand_albedo.png` | procedural ripples + noise, `make_assets.py` | this repo |
| Walking person (Gazebo only) | Gazebo Fuel model [`Mingfei/actor`](https://app.gazebosim.org/Mingfei/fuel/models/actor), file `meshes/walk.dae`, the same file gz-sim's `actor.sdf` example uses. Gazebo downloads it on first run into `~/.gz/fuel/` and caches it there. | CC BY 4.0 (per the Fuel API, 2026-10-12). Attribution: "actor" by Mingfei, Gazebo Fuel. It isn't copied into this repo. |

Colours come from `objects.yaml` (`color`), not from material files, so every simulator uses the same values. Gazebo logs "Missing material for shape" for these OBJs; that warning is expected.

Isaac (Part C) will need its own animated person asset; the path still comes from `scenes.yaml`.

Trash items (B5) have `visuals` in `objects.yaml`: an opaque, textured `_print` mesh (labels, caps, lids,
prints) and, for PET and glass, a plain `_body` mesh drawn see-through. `mesh` / `color` remain the
fallback. The visuals only change what the cameras see: sizes, masses and collisions are unchanged
(`tests/test_trash_visuals.py`). Isaac (Part C) imports the same OBJ files with their UVs and the same
PNG atlases; the see-through bodies need a transparent material there. `sim/gazebo/tools/visual_check.py`
renders them for a look (`results/b5/contact_sheet.png`).
