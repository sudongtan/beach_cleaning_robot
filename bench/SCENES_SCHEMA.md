# `bench/scenes.yaml` schema (version 1)

The benchmark scenes, described once and independently of any simulator. The file is generated by `sim/common/generate_scene.py` (`make generate`); never edit it by hand. Each simulator has a loader that builds a world from it (`sim/gazebo/load_scene.py`, later `sim/isaac/load_scene.py`). `sim/common/scene_schema.py` checks a file against this schema.

## Conventions

- **Units:** SI. Metres, kilograms, seconds, metres per second. Angles are radians, except fields ending in `_deg`.
- **Frame:** every pose is in the `map` frame (ENU). The origin is the south-west corner of the scene area, x points east, y points north, z points up. `z = 0` is the water level.
- **Poses** are `[x, y, yaw]`. Objects rest on the terrain, so loaders compute z from the terrain height (see `sim/common/terrain.py`). Yaw turns the object's model frame about z.
- **Model frames and sizes** come from `sim/common/objects.yaml`: origin at the centre of the footprint on the ground, x along the long axis.
- **Determinism:** a scene depends only on its own seed. Numbers are rounded to 3 decimals (yaw to 4).

## Top level

| Field | Type | Meaning |
|---|---|---|
| `schema_version` | int | `1` |
| `scenes` | list | one entry per seed, in the order requested |

## Scene

| Field | Type | Meaning |
|---|---|---|
| `seed` | int | scene id; seeds 0–9 are the benchmark |
| `area.size` | `[w, h]` | scene area, x from 0 to w, y from 0 to h. The sea is at the south (low y). |
| `geo` | map | `latitude_deg`, `longitude_deg`, `elevation_m` of the map origin (WGS84), for GNSS simulation |
| `terrain` | map | see below |
| `geofence.polygon` | list of `[x, y]` | the cleaning area (counter-clockwise). The waterline is excluded with a margin. Built from `config/geofence.yaml`. |
| `robot_start.pose` | `[x, y, yaw]` | robot spawn pose |
| `bins` | list | exactly 2: `id`, `model` (key in `objects.yaml: bins`), `bin_id` (`recyclable` / `residual`), `pose` |
| `landmarks` | list | `id`, `model` (key in `objects.yaml: landmarks`: `lifeguard_tower`, `fence_post`), `pose`. Static. |
| `trash` | list | `id` (`trash_NN`), `model` (key in `objects.yaml: trash`), `material` (`pet` / `metal` / `glass` / `residual`), `pose`, `half_buried` (bool), and `bury_fraction` (0–1, the share of the visual height below the surface; present only if `half_buried`) |
| `distractors` | list | `id` (`distractor_NN`), `model` (key in `objects.yaml: distractors`), `type` (`shell` / `rock` / `seaweed` / `driftwood`), `pose` |
| `person` | map or `null` | `id`, `speed` (m/s), `loop` (bool), `waypoints` (list of `[x, y]`). The person walks the polygon at constant speed, turns on the spot at each waypoint and, if `loop`, returns to the first waypoint and starts over. The first waypoint is outside the area. |

Ids are unique within a scene. The ground-truth topics and the benchmark use them to match items.

## Terrain

The height field is `terrain.height_at(terrain, x, y)` in `sim/common/terrain.py`. That function is the reference; this table describes its parameters.

| Field | Type | Meaning |
|---|---|---|
| `z_min`, `z_max` | m | heights are clamped to this range |
| `heightmap.pixels` | int | grid size n (2^k + 1) of the exported height array |
| `heightmap.size` | m | side of the square grid (covers the area, margins and sea) |
| `heightmap.center` | `[x, y]` | grid centre in the map frame |
| `waterline_y` | m | the shoreline runs along `y = waterline_y`. South of it: water, with the seabed sloping down from z = 0. |
| `wet_zone_width` | m | flat wet sand from `waterline_y` to `waterline_y + wet_zone_width` |
| `wet_zone_height` | m | height of the flat wet zone |
| `beach_slope` | rise/run | dry sand rises inland from the wet zone at this slope |
| `roughness` | list | sine components on dry sand: `amplitude` (m), `wavelength` (m), `direction_deg`, `phase` (rad) |
| `dunes` | list | Gaussian bumps on dry sand: `x`, `y`, `height` (m), `sigma_x`, `sigma_y` (m). Gentle ones lie inside the area; a steep ridge lies behind the fence (y > area). |
| `friction` | map | Coulomb μ per zone: `dry_sand`, `wet_sand` |

## Derived files (not in the scene file)

`sim/common/export_terrain.py --seed n` writes these to `sim/common/generated/scene_<n>/` (git-ignored):

- `heightmap.png`: 16-bit, row 0 = north, stretched so that pixel 0 is the lowest grid height and 65535 the highest
- `terrain.obj`: the same grid as a triangle mesh, in the map frame
- `traversability.npz` (`slope_deg`, `water`, `height`, `occupancy`) plus `traversability.pgm` and `.yaml` (map_server format). Covers the scene area at `config/terrain.yaml: grid_resolution_m`; cells are lethal if water or steeper than `max_slope_deg`.
